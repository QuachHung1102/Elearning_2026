## 1. Cách dùng

- Cỡ (tương đối, không lịch): **S** = một file hoặc vài dòng; **M** = một lát cắt qua vài file;
  **L** = nhiều lát cắt.
- Trạng thái: `todo`, `doing`, `done`, `blocked`. Chỉ đổi sang `done` khi lệnh ở cột **Kiểm
  tra** đã chạy và đạt.
- Không bắt đầu task khi task ở cột **Sau** chưa `done`. Cột **Đóng** là mã phát hiện trong
  REVIEW mà task giải quyết.
- Task lộ ra việc mới thì thêm một dòng mới, không nhét vào task cũ.
- Mọi task đi qua Definition of Done ở mục 5.
